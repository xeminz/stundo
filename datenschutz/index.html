Stundo Impressum

Datenschutzerklärung

Stand: November 2026

Kurz gesagt: Stundo hat keine Konten, keine Cookies, keine Werbung und kein Tracking. Deine HÜs und Tests liegen in deinem Browser und, damit Laptop und Handy dasselbe sehen, verschlüsselt übertragen auf einem kleinen Server bei Cloudflare. Dort sind sie nur über deinen geheimen Sync-Code erreichbar.

1. Verantwortlicher

Siehe Impressum.

2. Hosting der Website (GitHub Pages)

Die Website wird von GitHub Inc. bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie deine IP-Adresse. Siehe Datenschutzerklärung von GitHub.

3. Sync und Mitteilungen (Cloudflare)

Damit deine Geräte dieselben Daten sehen und du Mitteilungen bekommst, speichert ein Server bei Cloudflare Inc.:

  • deine Einträge (Fächer, HÜs, Tests, Stoff, Lernplan, Stundenplan, Einstellungen), abgelegt unter deinem zufälligen Sync-Code,
  • die Push-Adresse deiner Geräte (vom Browser bzw. von Apple, Google oder Microsoft vergeben).

Es werden keine Namen, E-Mail-Adressen oder Passwörter gespeichert. Gelöschte Einträge werden nach 60 Tagen endgültig entfernt. Wenn du Mitteilungen ausschaltest, wird die Push-Adresse gelöscht. Siehe Datenschutzerklärung von Cloudflare.

Mitteilungen werden über den Push-Dienst deines Geräts zugestellt (z. B. Apple). Der Inhalt ist dabei Ende-zu-Ende-verschlüsselt.

4. KI-Lernplan (Google Gemini)

Wenn du einen Lernplan erstellst, schickt dein Browser das Fach, das Datum, den Stoff und deine Termine direkt an Google Gemini. Dafür nutzt du deinen eigenen API-Key, der nur auf deinem Gerät gespeichert ist. Siehe Datenschutzerklärung von Google.

5. Deine Rechte

Du kannst deine Daten jederzeit in der App sichern (⚙️ → Sichern) und Einträge löschen. Für Auskunft oder vollständige Löschung am Server melde dich über die Kontaktdaten im Impressum und nenne deinen Sync-Code.
